Read a file from the local filesystem. If the path does not exist, an error is returned.

Usage:
- The path parameter should be an absolute path. Relative paths are resolved against the current working directory.
- By default, the tool returns up to 2000 lines from the start of the file.
- The offset parameter is the line number to start from (1-indexed).
- To read later sections, call this tool again with a larger offset.
- Use the grep tool to find specific content in large files or files with long lines.
- Use the glob tool to look up filenames by glob pattern when the exact path is unknown.
- Use list_dir when you need a directory listing instead of file content.
- Contents are returned with each line prefixed by its 1-indexed line number as `<n>: <content>`.
- Any line longer than 2000 characters is truncated with a marker.
- Binary files are not returned; an error is reported instead.
- Output is capped at 50 KB per call. When capped, the response includes an offset hint to continue.
- Call this tool in parallel when you need to read multiple files.
- Prefer reading a larger window once over many tiny repeated slices.
